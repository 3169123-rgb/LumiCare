Datos y tecnología

JSON

JSON significa JavaScript Object Notation. Es un formato utilizado para almacenar y transmitir información de una manera sencilla y organizada.

Es muy utilizado en aplicaciones web porque permite intercambiar información entre un navegador y un servidor.

¿Qué es JSON?

JSON es un formato de texto utilizado para representar información estructurada. Su sintaxis está basada en objetos y pares de clave-valor, por lo que resulta relativamente fácil de leer tanto para las personas como para los programas.

Aunque su nombre contiene la palabra JavaScript, JSON puede utilizarse con muchos lenguajes de programación.

¿Por qué JSON es importante?

JSON se convirtió en un formato muy utilizado para el intercambio de información en aplicaciones web y servicios digitales.

Su estructura sencilla facilita el envío de datos entre diferentes sistemas y aplicaciones.

Por ejemplo, una aplicación puede solicitar información a un servidor y recibir los resultados organizados en formato JSON.

Claves y valores

Clave

La clave identifica el dato que queremos almacenar. Por ejemplo: nombre, edad o correo.

Valor

El valor es la información asociada a una clave. Puede ser texto, número, verdadero o falso, un objeto o una lista.

Ejemplo de clave y valor

{
    "nombre": "LumiCare",
    "categoria": "Bienestar",
    "activo": true
}

Objetos y arrays en JSON

Objetos

Los objetos se escriben utilizando llaves { } y contienen pares de clave y valor. 

{
    "nombre": "Ana",
    "edad": 16
}

Arrays

Los arrays permiten almacenar varios valores dentro de una lista utilizando corchetes [ ]. 

{
    "colores": [
        "rosa",
        "blanco",
        "crema"
    ]
}

Objeto JavaScript vs JSON

Aunque JSON y los objetos de JavaScript pueden parecer similares, no son exactamente lo mismo.

Un objeto de JavaScript es una estructura que existe dentro del código y puede utilizarse directamente por el programa.

JSON es una representación en formato de texto que se utiliza principalmente para intercambiar información.

Objeto de JavaScript

const usuario = {
    nombre: "Ana",
    edad: 16
};

JSON

{
    "nombre": "Ana",
    "edad": 16
}

Convertir JSON y objetos

JSON.stringify()

Convierte un objeto de JavaScript en una cadena de texto con formato JSON. 

const texto = JSON.stringify(usuario);

JSON.parse()

Convierte una cadena JSON en un objeto que JavaScript puede utilizar. 

const objeto = JSON.parse(texto);

JSON, APIs y servidores

JSON es muy utilizado cuando una página web necesita comunicarse con un servidor mediante una API.

Una API puede recibir una solicitud y devolver información estructurada en formato JSON para que JavaScript pueda utilizarla y mostrarla en la página.

1. Navegador

La página realiza una solicitud de información.

2. Servidor

El servidor procesa la solicitud y prepara los datos.

3. JSON

La información puede regresar organizada en formato JSON.

Ejemplo práctico de JSON

Imaginemos que LumiCare necesita enviar información sobre un producto. Los datos podrían representarse así: 

{
    "producto": "LumiCare Smart",
    "categoria": "Bienestar",
    "precio": 49.99,
    "disponible": true,
    "caracteristicas": [
        "Tecnología inteligente",
        "Diseño moderno",
        "Fácil de usar"
    ]
}

De esta manera, diferentes aplicaciones pueden interpretar y utilizar la información del producto.

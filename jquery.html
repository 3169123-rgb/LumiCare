jQuery

jQuery es una biblioteca de JavaScript creada para facilitar el desarrollo de páginas web interactivas. Permite realizar diferentes tareas utilizando una sintaxis más sencilla y corta.

Con jQuery se pueden seleccionar elementos HTML, modificar contenido, responder a eventos y crear animaciones de una manera práctica.

¿Qué es jQuery?

jQuery es una biblioteca de JavaScript de código abierto. Fue diseñada para simplificar tareas comunes del desarrollo web, como manipular el contenido de una página, trabajar con eventos, realizar animaciones y comunicarse con servidores.

Su sintaxis permite escribir determinadas operaciones con menos código que utilizando JavaScript tradicional.

¿Por qué nació jQuery?

jQuery apareció para facilitar el desarrollo de aplicaciones web y reducir algunas diferencias entre los navegadores de la época.

Su objetivo era proporcionar una forma más sencilla de seleccionar elementos, manejar eventos, realizar animaciones y trabajar con páginas web dinámicas.

La sintaxis $ de jQuery

El símbolo $

Una de las características más conocidas de jQuery es el uso del símbolo $. Este símbolo permite acceder a las funciones principales de la biblioteca.

Seleccionar elementos

jQuery permite seleccionar elementos HTML mediante selectores similares a los utilizados en CSS.

Ejemplo básico

$("#mensaje").text("Hola desde jQuery");

En este ejemplo, jQuery busca el elemento que tiene el identificador mensaje y cambia su contenido.

Ventajas y desventajas de jQuery

✓ Ventajas

• Sintaxis sencilla.
• Facilita la manipulación del DOM.
• Permite manejar eventos fácilmente.
• Incluye métodos para animaciones.
• Fue muy utilizado en proyectos web.

✗ Desventajas

• Puede agregar una dependencia adicional al proyecto.
• Muchas funciones modernas de JavaScript ya pueden realizarse sin jQuery.
• En proyectos nuevos puede no ser necesario.

jQuery vs JavaScript moderno

JavaScript moderno incluye muchas funciones que anteriormente eran más complicadas de realizar de manera compatible entre navegadores.

Por esta razón, actualmente muchas tareas que antes se realizaban con jQuery pueden hacerse directamente con JavaScript utilizando métodos modernos del DOM.

JavaScript moderno

document.querySelector("#mensaje").textContent =
"Hola desde JavaScript";

jQuery

$("#mensaje").text("Hola desde jQuery");

Animaciones con jQuery

jQuery incluye métodos que permiten crear animaciones de manera sencilla.

Dos ejemplos conocidos son fadeIn() y slideToggle().

Ejemplo práctico: fadeIn()

El método fadeIn() permite mostrar un elemento utilizando una transición de aparición.

¡Hola! Esta caja puede aparecer y desaparecer. 
$("#cajaFade").fadeIn();
$("#cajaFade").fadeOut();

Ejemplo práctico: slideToggle()

El método slideToggle() permite mostrar u ocultar un elemento utilizando un efecto de desplazamiento.

Este contenido se puede mostrar y ocultar. 
$("#cajaSlide").slideToggle();

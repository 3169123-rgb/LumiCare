Hosting y Dominios

El hosting y los dominios son elementos importantes para publicar un sitio web y permitir que otras personas puedan acceder a él mediante Internet.

El hosting almacena los archivos de una página web, mientras que el dominio funciona como una dirección que permite encontrar ese sitio.

¿Qué es el hosting?

El hosting, también llamado alojamiento web, es un servicio que proporciona espacio y recursos en un servidor para almacenar los archivos de un sitio web.

Cuando una persona visita una página web, el navegador solicita los archivos al servidor donde está alojado el sitio.

De esta forma, el contenido puede estar disponible para los usuarios a través de Internet.

Tipos de hosting

Hosting compartido

Varios sitios web utilizan recursos de un mismo servidor. Es una opción sencilla para proyectos pequeños y sitios que no necesitan muchos recursos.

VPS

Un servidor privado virtual proporciona recursos asignados a un proyecto dentro de un servidor físico. Ofrece mayor control que un hosting compartido.

Cloud Hosting

Utiliza recursos distribuidos en diferentes servidores. Puede ofrecer flexibilidad y capacidad para adaptarse a diferentes necesidades.

Vercel para sitios estáticos

¿Qué es Vercel?

Vercel es una plataforma utilizada para desplegar aplicaciones y sitios web. Es especialmente práctica para proyectos desarrollados con tecnologías web como HTML, CSS y JavaScript.

Para un proyecto como LumiCare, un sitio compuesto por archivos HTML, CSS, JavaScript e imágenes puede publicarse en una plataforma de este tipo.

Después del despliegue, el proyecto puede quedar disponible mediante una dirección web.

¿Qué es un dominio?

Un dominio es una dirección fácil de recordar que permite acceder a un sitio web.

En lugar de tener que recordar una dirección numérica del servidor, los usuarios pueden utilizar un nombre de dominio.

Partes de un dominio

Nombre de dominio

Es la parte principal que identifica al sitio. Por ejemplo, en lumicare.com, "lumicare" es el nombre elegido.

TLD

TLD significa Top-Level Domain. Es la terminación del dominio, como .com, .org o .net.

lumicare.com

¿Qué es un subdominio?

Un subdominio es una parte adicional que se coloca antes del dominio principal. Puede utilizarse para organizar diferentes áreas de un sitio web.

blog.lumicare.com

En este ejemplo, blog sería el subdominio y lumicare.com sería el dominio principal.

¿Qué es DNS?

DNS significa Domain Name System. Su función principal es ayudar a relacionar los nombres de dominio con las direcciones de los servidores correspondientes.

Gracias al DNS, los usuarios pueden escribir un nombre de dominio en lugar de tener que recordar directamente una dirección IP.

1. Usuario

Escribe un dominio en el navegador.

2. DNS

El sistema busca la información asociada al dominio.

3. Servidor

El navegador puede conectarse con el servidor correspondiente.

Propagación DNS

Cuando se realizan cambios en la configuración DNS de un dominio, la información puede tardar un tiempo en actualizarse en diferentes servidores y redes de Internet.

Este proceso se conoce como propagación DNS. Durante este período, algunos usuarios pueden recibir la información anterior mientras otros ya reciben la nueva configuración.

Hosting + dominio

Hosting

Guarda los archivos y recursos necesarios para que el sitio web funcione.

Dominio

Proporciona una dirección fácil de recordar para acceder al sitio.

Sitio web

Es el resultado que el usuario puede visitar desde un navegador utilizando el dominio.

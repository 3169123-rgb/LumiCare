JavaScript

El lenguaje que permite agregar interactividad a las páginas web.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación utilizado principalmente para agregar comportamiento e interactividad a las páginas web.

Con JavaScript podemos hacer que los botones respondan a acciones, cambiar contenido, validar formularios, mostrar mensajes y realizar diferentes funciones.


HTML vs CSS vs JavaScript

HTML

Crea la estructura y los elementos de una página web.

CSS

Se encarga del diseño, colores, tamaños y presentación.

JavaScript

Agrega comportamiento e interactividad.


Variables, funciones y eventos

Variables

Guardan información que puede utilizar el programa. 

let nombre = "LumiCare";

Funciones

Son bloques de código que realizan una tarea. 

function saludar() {
    alert("Hola");
}

Eventos

Ejecutan una acción cuando ocurre algo como un clic. 

button.addEventListener("click", funcion);
